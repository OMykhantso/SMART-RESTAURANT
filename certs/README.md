# Сертифікати HTTPS для localhost

Тут зберігаються `localhost.pem` і `localhost-key.pem` для nginx (Docker, https://localhost:8443).
Файли не комітяться в git.

- **Довірений сертифікат (рекомендовано):** `./scripts/setup-https.sh` — створює сертифікат через
  [mkcert](https://github.com/FiloSottile/mkcert), браузер показує «замочок» без попереджень.
- Якщо тут порожньо, контейнер `web` сам створить **самопідписаний** сертифікат — сайт працює по HTTPS,
  але браузер один раз попросить підтвердити виняток безпеки.
