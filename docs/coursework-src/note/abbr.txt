# Скорочення і терміни для переліку (@abbr). У документ потрапляють лише ті, що трапляються в його тексті.
# Формат: СКОРОЧЕННЯ | розшифрування
БД | база даних
КТ | контрольна точка
ТЗ | технічне завдання
API | Application Programming Interface, програмний інтерфейс застосунку
CI | Continuous Integration, безперервна інтеграція: автоматична перевірка коду після кожної зміни
CORE | обовʼязкове функціональне ядро системи за методичними вказівками
ADVANCED | компоненти підвищеної складності, визначені темою курсової роботи
BONUS | функціональність понад основні вимоги
CRUD | Create, Read, Update, Delete — базові операції з даними
CVC | Card Verification Code, код перевірки платіжної картки
E2E | end-to-end, наскрізне тестування через інтерфейс користувача
ER | Entity–Relationship, модель «сутність – звʼязок»
ETA | Estimated Time of Arrival, прогнозований час готовності або доставки
FK | Foreign Key, зовнішній ключ
FR | Functional Requirement, функціональна вимога
GPS | Global Positioning System, супутникова система визначення місцезнаходження
HTTP/HTTPS | HyperText Transfer Protocol (Secure), протокол передавання даних у вебі (захищений TLS)
JSON | JavaScript Object Notation, текстовий формат обміну даними
JWT | JSON Web Token, токен доступу з цифровим підписом
KDS | Kitchen Display System, екран черги замовлень на кухні
ORM | Object-Relational Mapping, обʼєктно-реляційне відображення
PK | Primary Key, первинний ключ
POS | Point of Sale, робоче місце для оформлення замовлень і оплат
QR | Quick Response code, двовимірний штрихкод
RBAC | Role-Based Access Control, керування доступом на основі ролей
REST | Representational State Transfer, архітектурний стиль вебсервісів
SHA-256 | криптографічна геш-функція сімейства SHA-2
SQL | Structured Query Language, мова запитів до реляційних баз даних
TC | Test Case, тестовий сценарій
TLS | Transport Layer Security, протокол шифрування з’єднання
UC | Use Case, варіант використання
UI/UX | User Interface / User Experience, інтерфейс і досвід користувача
UK | Unique Key, унікальний ключ
URL | Uniform Resource Locator, адреса ресурсу в мережі
3-D Secure | протокол додаткового підтвердження платежу карткою кодом від банку
3НФ | третя нормальна форма відношень
Booking engine | алгоритм пошуку вільних слотів і вибору столика
Check-in | реєстрація прибуття гостя в ресторан
Endpoint | адреса й HTTP-метод окремої операції API
Kitchen display | екран кухні з чергою замовлень і таймерами
No-show | неявка гостя за підтвердженим бронюванням
Sandbox | тестовий режим платіжного шлюзу без списання коштів
Walk-in | гість, який прийшов без попереднього бронювання
мс | мілісекунда
хв | хвилина
км | кілометр
коп. | копійка
px | піксель (одиниця розміру зображення на екрані)
МБ | мегабайт
